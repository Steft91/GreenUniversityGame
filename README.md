# Campus Verde: Mision Green University

Videojuego educativo desarrollado con Phaser 3 y Vite. El proyecto propone una experiencia interactiva sobre sostenibilidad ambiental en un contexto universitario, combinando clasificacion de residuos, energias renovables, solucion de problemas ambientales y un reto opcional de reconocimiento institucional.

## Tecnologias

- Phaser 3
- Vite
- JavaScript ES Modules

## Instalacion

```bash
npm install
```

## Ejecutar en desarrollo

```bash
npm run dev
```

Luego abre la URL que muestre Vite en la terminal, normalmente:

```text
http://localhost:5173
```

## Compilar version final

```bash
npm run build
```

## Previsualizar build

```bash
npm run preview
```

## Flujo del juego

El juego inicia en el menu principal y avanza por estas escenas:

1. Nivel 1 - Oceano
2. Nivel 1 - Parque
3. Nivel 2 - Energias renovables
4. Nivel 3 - Problema y solucion
5. Pantalla de decision
6. Reto opcional - Departamentos
7. Resultado final
